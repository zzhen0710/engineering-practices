# Notes

这里用于记录 Linux / C++ 工程学习过程中的知识、实验与实践经验。

与 `snippets/`、`components/` 和 `templates/` 不同，本目录允许保留完整的学习与探索过程，包括问题分析、实际操作、实验结果和错误排查。

## 收录原则

- 来自真实学习与实践
- 记录值得长期保留的知识和实验
- 允许保留尚未抽象成熟的内容
- 已形成稳定复用价值的经验，可以进一步提炼到其他目录
- 避免重复维护相同内容
