# Notes

这里用于记录 Linux / C++ 工程学习过程中的知识、实验与实践经验。

独立的工程实验可以在此完整记录问题、操作和结果；已有项目中的问题，保留理解可迁移结论所需的过程，其完整源码、测试与故障记录仍留原项目。与 `snippets/`、`components/` 和 `templates/` 不同，本目录允许保留尚未抽象成熟的探索。

## 收录原则

- 来自真实学习与实践
- 记录值得长期保留的知识和实验
- 尚未验证的探索可以保留，但必须注明状态，不能作为已验证范式
- 已形成稳定复用价值的经验，可以进一步提炼到其他目录
- 避免重复维护相同内容；同主题纠错优先整合原文，项目特定过程引用原仓
- 长文按主题相关性和查阅负担决定是否拆分，不按长度自动拆分；保留关键推导，不无节制追加
